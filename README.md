# koa-banc-qg

Le QG du cluster « banc » : le banc de recette du framework agentique de KoA. Une petite équipe d'agents y mène un
micro-chantier, pour mesurer comment elle travaille. Voir [koa-banc-forge](https://github.com/Happykiller/koa-banc-forge)
pour la forge locale, et les seeds `koa-banc-*` pour les agents.
